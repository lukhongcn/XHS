# Label Parser Engine 設計說明

## 1. 目的

建立 MES 通用標籤解析引擎。

目標：

-   支援客戶標籤解析
-   支援 MES 自有標籤解析
-   不同客戶不同格式
-   新增客戶只修改資料庫規則，不修改程式
-   統一輸出 LabelInfo 模型

本模組只負責：

> 原始標籤 → 規則解析 → 統一資料模型

暫不包含掃描記錄、追溯關聯、業務流程。

------------------------------------------------------------------------

# 2. 整體架構

    掃描條碼
        |
        v
    LabelParser
        |
        v
    LabelRule
        |
        +----------------+
        |                |
    KEY_VALUE       POSITION       FIX_LENGTH
    編號型          位置型          固定長度型
        |                |              |
        +----------------+--------------+
                         |
                         v
                  LabelInfo

# 3. 支援解析方式

## 3.1 KEY_VALUE 編號型

範例：

    10#202004112AA$11#3051$17#60$

解析：

  Key   Value         欄位
  ----- ------------- ----------------
  10    202004112AA   MaterialNo
  11    3051          CustomerPartNo
  17    60            Qty

說明：

-   Key 代表欄位編號
-   不同客戶 Key 意義不同
-   必須由規則表配置

------------------------------------------------------------------------

## 3.2 POSITION 位置型

範例：

    ABC001$3051$60

規則：

  位置   欄位
  ------ ----------------
  1      MaterialNo
  2      CustomerPartNo
  3      Qty

------------------------------------------------------------------------

## 3.3 FIX_LENGTH 固定長度型

範例：

    26J033260530500

規則：

  開始位置   長度   欄位
  ---------- ------ ------------
  1          5      MaterialNo
  6          6      BatchNo
  12         3      Qty

------------------------------------------------------------------------

# 4. 資料庫設計

## 4.1 標籤規則主表

表：

    tb_LabelCodeRule

作用：

定義一種標籤的解析方式。

欄位：

  欄位           說明
  -------------- ------------------------
  RuleId         規則ID
  RuleName       規則名稱
  LabelType      標籤類型(Customer/MES)
  CustomerId     客戶
  ParseType      解析方式
  Separator      分隔符
  KeySeparator   Key分隔符
  Version        版本
  Enabled        是否啟用
  Remark         備註

------------------------------------------------------------------------

## 4.2 標籤字段解析規則表

表：

    tb_LabelCodeRuleField

作用：

定義標籤內容如何映射到 MES 欄位。

欄位：

  欄位            說明
  --------------- ------------------
  Id              主鍵
  RuleId          規則ID
  FieldName       目標欄位
  DataType        資料類型
  KeyCode         編號模式 Key
  Position        位置模式順序
  StartPosition   固定長度開始位置
  Length          固定長度
  BatchRuleId     批次規則
  Required        是否必要
  SortNo          排序

------------------------------------------------------------------------

# 5. 字段類型

表：

    tb_FieldType

作用：

定義欄位如何解析。

欄位：

  欄位          說明
  ------------- ----------
  TypeCode      類型代碼
  TypeName      名稱
  ParserClass   解析類別

範例：

  TypeCode   說明
  ---------- ------
  STRING     文字
  NUMBER     整數
  DECIMAL    數量
  DATE       日期
  BATCH      批次

------------------------------------------------------------------------

# 6. 批次規則

表：

    tb_BatchRule

作用：

解析不同批次格式。

例如：

## 年月日

原始：

    260602

規則：

    YYMMDD

結果：

    2026-06-02

------------------------------------------------------------------------

## 年+週

原始：

    2625

規則：

    YYWW

結果：

    2026年第25週

------------------------------------------------------------------------

欄位：

  欄位          說明
  ------------- --------
  BatchRuleId   規則ID
  RuleName      名稱
  Format        格式
  Length        長度
  Remark        說明

------------------------------------------------------------------------

# 7. 統一輸出模型

``` csharp
public class LabelCodeInfo
{
    public string RawCode { get; set; }

    public string MaterialNo { get; set; }

    public string CustomerPartNo { get; set; }

    public string BatchNo { get; set; }

    public DateTime? BatchDate { get; set; }

    public int? BatchWeek { get; set; }

    public decimal Qty { get; set; }
}
```

------------------------------------------------------------------------

# 9. 解析流程

1.  掃描條碼

2.  根據客戶/標籤類型取得 LabelRule

3.  根據 ParseType 解析：

-   KEY_VALUE
-   POSITION
-   FIX_LENGTH

4.  根據 LabelRuleField 映射字段

5.  如果字段類型為 BATCH：

呼叫 BatchParser

6.  返回 LabelInfo

------------------------------------------------------------------------

# 10. 新增客戶流程

新增客戶標籤：

不修改程式。

只增加：

## tb_LabelRule

新增解析方式。

## tb_LabelRuleField

配置欄位。

## tb_BatchRule

如果批次格式特殊，增加批次規則。

------------------------------------------------------------------------

# 11. 設計原則

解析引擎只負責：

    字符串
       |
    解析
       |
    LabelInfo

不負責：

-   入庫
-   裝箱
-   出貨
-   追溯

後續業務模組建立在 LabelInfo 基礎上。

------------------------------------------------------------------------

# 12. 最終支持格式

支持：

-   KEY_VALUE 編號標籤
-   POSITION 順序標籤
-   FIX_LENGTH 固定長度標籤
-   日期批次
-   年週批次
-   客戶標籤
-   MES 自有標籤
